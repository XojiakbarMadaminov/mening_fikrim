# “Maʼmuriy tartib-taomillar toʻgʻrisida”gi Oʻzbekiston Respublikasi Qonuni haqida

Oʻzbekiston Respublikasi Oliy Majlisining Qonunchilik palatasi tomonidan 2025-yil 9-sentabr kuni qabul qilingan “Maʼmuriy tartib-taomillar toʻgʻrisida”gi Oʻzbekiston Respublikasi Qonunini koʻrib chiqib, Oʻzbekiston Respublikasi Konstitutsiyasining 99-moddasiga va “Oʻzbekiston Respublikasi Oliy Majlisining Senati toʻgʻrisida”gi Oʻzbekiston Respublikasi Konstitutsiyaviy Qonunining 23-moddasiga muvofiq Oʻzbekiston Respublikasi Oliy Majlisining Senati qaror qiladi:

1. “Maʼmuriy tartib-taomillar toʻgʻrisida”gi Oʻzbekiston Respublikasi Qonuni Senatning Sud-huquq masalalari va korrupsiyaga qarshi kurashish qoʻmitasining mazkur Qonun boʻyicha xulosasida bayon etilgan asoslarga koʻra rad etilsin.

2. Mazkur Qaror Oʻzbekiston Respublikasi Oliy Majlisining Qonunchilik palatasiga yuborilsin.

3. Ushbu Qaror qabul qilingan kundan eʼtiboran kuchga kiradi.
