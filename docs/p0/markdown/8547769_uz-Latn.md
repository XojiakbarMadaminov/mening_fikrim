# «O'zbekiston Respublikasining Konstitutsiyaviy sudi to'g'risida»gi O'zbekiston Respublikasi Konstitutsiyaviy Qonuni haqida

Oʻzbekiston Respublikasi Oliy Majlisining Qonunchilik palatasi tomonidan 2026-yil 29-sentabr kuni qabul qilingan «Oʻzbekiston Respublikasining Konstitutsiyaviy sudi to'g'risida»gi Oʻzbekiston Respublikasi Konstitutsiyaviy Qonunini ko'rib chiqib, Oʻzbekiston Respublikasi Konstitutsiyasining 93-moddasiga muvofiq Oʻzbekiston Respublikasi Oliy Majlisining Senati qaror qiladi:

1. «Oʻzbekiston Respublikasining Konstitutsiyaviy sudi to'g'risida»gi Oʻzbekiston Respublikasi Konstitutsiyaviy Qonuni ma'qullansin.

2. Оʻzbekiston Respublikasi Vazirlar Mahkamasi ushbu Konstitutsiyaviy Qonun rasmiy e'lon qilingan kundan e'tiboran ikki оy muddatda:

hukumat qarorlarining ushbu Konstitutsiyaviy Qonunga muvofiqlashtirilishini;

respublika ijro etuvchi hokimiyat organlari ushbu Konstitutsiyaviy Qonunga muvofiq o'z normativ-huquqiy hujjatlarini qayta ko'rib chiqishlari va bekor qilishlarini ta'minlasin;

amalga oshirilgan ishlar to'g'risida Оʻzbekiston Respublikasi Oliy Majlisining Senatiga axborot kiritsin.

3. Oʻzbekiston Respublikasi Oliy Majlisi Senatining Sud-huquq masalalari va korrupsiyaga qarshi kurashish qo'mitasi mazkur qaror ijrosi bo'yicha Oʻzbekiston Respublikasi Vazirlar Mahkamasining axborotini ko'rib chiqib, natijalari yuzasidan ikki hafta muddatda Oʻzbekiston Respublikasi Oliy Majlisi Senatining Kengashiga axborot kiritsin.

4. Ushbu Qaror qabul qilingan kundan e'tiboran kuchga kiradi.

O'zbekiston Respublikasi Oliy Majlisi Senatining Raisi Т. NARBAYEVA
