# «Маъмурий тартиб-таомиллар тўғрисида»ги Ўзбекистон Республикаси Қонуни ҳақида

Ўзбекистон Республикаси Олий Мажлисининг Қонунчилик палатаси томонидан 2025 йил 9 сентябрь куни қабул қилинган «Маъмурий тартиб-таомиллар тўғрисида»ги Ўзбекистон Республикаси Қонунини кўриб чиқиб, Ўзбекистон Республикаси Конституциясининг 99-моддасига ва «Ўзбекистон Республикаси Олий Мажлисининг Сенати тўғрисида»ги Ўзбекистон Республикаси Конституциявий Қонунининг 23-моддасига мувофиқ Ўзбекистон Республикаси Олий Мажлисининг Сенати қарор қилади:

1. «Маъмурий тартиб-таомиллар тўғрисида»ги Ўзбекистон Республикаси Қонуни Сенатнинг Суд-ҳуқуқ масалалари ва коррупцияга қарши курашиш қўмитасининг мазкур Қонун бўйича хулосасида баён этилган асосларга кўра рад этилсин.

2. Мазкур Қарор Ўзбекистон Республикаси Олий Мажлисининг Қонунчилик палатасига юборилсин.

3. Ушбу Қарор қабул қилинган кундан эътиборан кучга киради.
